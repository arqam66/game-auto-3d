## 🕹️ Controls

| Input | Key / Action | In-Game Effect |
|---|---|---|
| `W` / `↑` | Accelerate / Gas | Throttle forward acceleration |
| `S` / `↓` | Brake / Reverse | Slow down or reverse |
| `A` / `←` | Steer Left | Turn front wheel left with body roll |
| `D` / `→` | Steer Right | Turn front wheel right with body roll |
| `Space` / `Shift` | Drift | Slide into turns, accumulate drift score & recharge Nitro |
| `N` / `Ctrl` | Nitro Boost | Supercharged rocket acceleration with widened camera FOV |
| Buttons | Day / Dusk / Night | Switch real-time lighting and vehicle headlights |
| `P` | Pause / Resume | Toggle pause menu |

## 🚀 Running the Game

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or build and launch production server
npm run build
npm run start
```

Visit [http://localhost:3000](http://localhost:3000).
